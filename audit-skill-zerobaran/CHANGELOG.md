# Changelog — Audit-Skill-ZeroBaran
## [1.0.0] — 2026-11-03 — الإصدار الأول (مشروع #35)
### Added
- محرك فحص أصلي بـ 40+ قاعدة (أسرار/حقن/فك تسلسل/تشفير/SSRF/Docker/اعتماديات + ثغرات وكلاء LLM وفق OWASP LLM Top 10).
- تدرّج محركات مجاني: Semgrep OSS → Bandit → المحرك الأصلي (يعمل دائماً بلا اعتماديات).
- عقل تدقيق ذكي Groq→Gemini→MockBrain مع إخفاء الأسرار قبل الإرسال وشرح عربي + كود إصلاح جاهز.
- أرشيف Supabase (جدولان + 3 عروض + RLS) مع fallback JSON محلي وتتبع اتجاه الوضع الأمني.
- إنذارات تليجرام بالصيغة المعلنة (تنبيه عاجل/سبب/إصلاح مقترح) + ملخص أسبوعي.
- بوابة CI في GitHub Actions توقف النشر عند CRITICAL (exit 3) + مسح مجدول كل 6 ساعات.
- مركز قيادة Streamlit بخمسة تبويبات عربية.
- حزمة أمثلة: مستودع مُثقب (31 رصداً، BLOCKED 0/100) ومهارة نظيفة (APPROVED 100/100).
- اختبار عقود 33/33 يعمل دون مفاتيح أو اتصال.
