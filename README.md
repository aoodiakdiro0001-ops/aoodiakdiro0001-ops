## 📖 ما هو Cyber-SentinelBaran؟

منظومة ذكية متكاملة تقوم بـ:

- ✅ **فحص أمني شامل** — تمشيط الأكواد والخوادم بحثاً عن الثغرات الشهيرة (OWASP Top 10)
- ✅ **اكتشاف الثغرات** — اكتشاف ثغرات حقن SQL، كلمات المرور الصلبة، ثغرات الإدخال
- ✅ **تحليل ذكي بالـ AI** — تقييم خطورة الثغرات وتوليد كود الإصلاح الآمن تلقائياً
- ✅ **حماية استباقية** — اكتشاف الثغرات قبل استغلالها من المخترقين
- ✅ **تنبيهات فورية** — إشعارات عاجلة على تليجرام فور اكتشاف أي ثغرة حرجة
- ✅ **سيادة وخصوصية تامة** — فحصك الأمني يتم محلياً أو عبر أدوات مفتوحة المصدر

**كل هذا — بدون دفع دولار واحد!**

## 🛠️ التقنيات المستخدمة (Free Tech Stack)

| المكون | التقنية | الدور |
|--------|---------|-------|
| ⚙️ التشغيل | GitHub Actions | خادم مجاني لتنفيذ عمليات الفحص الأمني دورياً |
| 🐛 الفحص | Semgrep + Nuclei | أدوات مفتوحة المصدر لفحص الأكواد واكتشاف الثغرات |
| 🌐 الشبكات | Nmap | مسح منافذ الشبكات واكتشاف الخدمات المعرضة للخطر |
| 🧠 التحليل | Google Gemini API | تحليل الثغرات وتقييم الخطورة وتوليد كود الإصلاح |
| 💾 التخزين | Supabase | تخزين سجلات الفحص وحالة الثغرات عبر الزمن |
| 📨 التنبيهات | Telegram Bot API | إرسال إنذارات أمنية عاجلة مع تفاصيل الإصلاح |

## 🏗️ البنية المعمارية

```
[مستودع الكود أو الخوادم المستهدفة]
```
